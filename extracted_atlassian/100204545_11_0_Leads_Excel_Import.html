1. Objective

Enable users to import leads from Excel while the system automatically:

  • Detects duplicates

  • Updates existing leads

  • Creates new leads

  • Associates leads with existing customers

The system must rely on Lead Status + Mandatory Fields per Status to determine:

  • whether a lead is new

  • whether it already exists

  • whether a conflict requires user review

The Excel file must remain simple.

Users should not manage IDs or import modes.

2. Core Design Principles

The system must follow these rules:

Excel must stay simple

The user should only upload lead data.

The Excel file must NOT contain:

  • Lead IDs

  • Import modes

  • New/Update indicators

  • Override flags

All decisions are made inside the system.

Lead Status determines required data

Each lead status requires a minimum dataset.

This dataset becomes the lead identity used to detect duplicates.
