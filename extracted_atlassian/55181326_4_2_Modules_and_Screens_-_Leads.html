AI Logic

·       Analyzes communication history, follow-up frequency, and response sentiment to calculate a Conversion Probability Score (0–100%).

·       Flags leads as:

o   High Potential – 70–100%

o   Needs Attention – 40–69%

o   Low Engagement – <40%

·       Suggests best next actions and timing using behavioral prediction (e.g., “Tomorrow 2–4 PM best for response”).

·       Refreshes daily based on activity logs and message analysis.

UI Behavior Notes

·       Hovering AI badges shows detailed reasoning (“Low engagement – no reply in 5 days”).

·       Clicking a lead name opens the detailed lead view.

·       Right panel dynamically updates when selecting a lead row.

·       AI insights refresh asynchronously (no full page reload).

User Flow

  1. User opens the Leads module → system loads all active leads.

  2. The AI Insights panel highlights top-priority leads.

  3. User filters by AI Priority or Status.

  4. Clicking a row expands the lead details or opens a side drawer.

  5. From insights, the user can generate an estimate or assign a PM in one click.

  6. The AI engine updates prediction scores overnight.

AI Logic

·       Monitors archived leads for reactivation potential (e.g., new customer activity or engagement).

·       Periodically re-scores archived leads with updated AI conversion models:

o   If new signals detected, the system suggests “Reopen Lead”.

·       Detects duplicates automatically and tags them as “Merged / Duplicate Source”.

·       Generates monthly “Lost Opportunity” analytics to highlight trends (e.g., common reasons for loss).

UI Behavior Notes

·       Tabbed navigation filters by archive reason or nurturing status.

·       Restore instantly moves the lead back to the active pipeline under the original PM.

·       Delete requires Admin confirmation.

·       All changes log to Activity History for compliance.

User Flow

  1. User selects Leads → Archived from the sidebar.

  2. System loads all archived records by default under “Unqualified / On Hold”.[GU3] [CE4] 

  3. User filters or exports data.

  4. Optionally restores or deletes selected leads.

  5. AI engine periodically scans this list and pushes recommendations like “Michael Brown may be reactivated – last inquiry 7 days ago” to the AI Insights panel.

AI Logic

·       Behavioral Pattern Detection:
AI tracks historical response rates and suggests optimal follow-up intervals dynamically.
Example: “Typical customer response: 8 hours → Recommend reducing first follow-up to 12 hours.”

·       Adaptive Escalation:
When a lead remains untouched beyond threshold, AI evaluates lead score and suggests either Auto Assign to New Rep or Deprioritize.

·       Predictive Workload Balancing:
AI checks PM/sales rep workload before assigning escalated leads to prevent overload.

UI Behavior Notes

·       Intervals are selectable in hours/days (validated numerically).

·       Disabled toggles gray out dependent inputs.

·       If the Enable Lead Escalation toggle is active, “Escalation Threshold” and “Escalation Action” become required fields.

·       The Save Changes button activates only if unsaved edits exist.

·       Successful save triggers toast: “Lead settings updated successfully.”

User Flow

  1. Admin opens Leads → Settings.

  1. Toggles Automatic Follow-up Reminders ON and defines timing.

  1. (Optional) Enables Lead Escalation and chooses threshold + escalation action.

  1. Clicks Save Changes → confirmation message appears.

  1. AI system recalibrates reminders and escalation triggers based on new settings.
