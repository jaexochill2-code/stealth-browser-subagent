Additional points :

 

1. Inactive Agent Routing

While several specialized agents are registered in the system, they are currently excluded as direct router destinations. This means the bot cannot currently route users to:

  • lead_attachment_agent: For managing lead-related files and documents.

  • task_agent: For general task management operations.

  • task_attachment_agent: For handling task-level file uploads and archiving.

2. Limited Project Functionality

Although the system has a wide array of implemented project tools, the PROJECT_TOOL_CLASSES currently only exposes a subset focused on listing, details, and checklists. The following implemented features are not currently active in the bot's project toolset:

  • Project Creation & Updates: CreateProjectTool and UpdateProject.

  • Financials: GetProjectBudget and UpdateAllocatedBudget.

  • Status Management: Tools to set projects "On Hold," "Activate," "Restore," or "Archive".

  • Intelligence: AssessProjectRisks (the helper for computing risk summaries).

3. Lead Creation Restrictions

The bot approach to creating leads is currently restricted to a single path:

  • Primary Active Flow: Lead creation is executed exclusively via the create_lead_subagent.

  • Missing Exposure: Standard tool-based lead creation classes remain implemented in the codebase but are not exposed in the current get_lead_tools() configuration.

4. Functional Gaps in Existing Tools

There are specific missing capabilities or constraints within the tools that are active:

  • Unsupported Lead Filters: The bot explicitly lacks the ability to filter leads by geographic location (city, state, or area).

  • Role Limitations: When inviting new users, the bot is restricted to only two roles: Sales Manager and Project Manager, other roles are either not supported or not allowed for invitation via this tool - User permission

  • Task Transition Logic: The UpdateTaskStatus tool is strictly forward-moving, backward transitions ( from "Completed" back to "In Progress") are strictly forbidden and not supported by the bot's logic.
