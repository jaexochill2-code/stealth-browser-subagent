1. Overview

The Location system enables GCC admins to monitor subcontractors in real time, while also providing a geographic view of projects, leads, and workforce across the United States.

The system includes:

  • Project-level location tracking (execution view)

  • Global map view (portfolio + operations view)

Mobile app provides location data → Web provides monitoring, insights, and control.

2. Goals

Primary Goals

  • Real-time visibility of subcontractors

  • Improve on-site accountability

  • Detect operational issues early

Secondary Goals

  • Visualize projects and leads geographically

  • Support multi-region scaling (US-wide)

3. Scope

In Scope

  • Project Location tab (map + logs)

  • Global Map View (Projects / Leads / Workforce)

  • US-wide map with zoom

  • Smart clustering

  • Geofencing + status calculation

  • Filtering (status, type, role, location)

  • Mobile → Web location sync

Out of Scope (Phase 1)

  • Route tracking

  • Historical heatmaps

  • Offline tracking

  • International maps

4. Users

  • GCC Admin (primary)

  • Project Manager

  • Operations team
