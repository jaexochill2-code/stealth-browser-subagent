1. Objective

Design a unified, scalable notification system across EZBuild that:

  • Works across Web and Mobile for ALL roles (GCC, Team, Subcontractor, Customer)

  • Covers all business domains

  • Delivers actionable, role-based notifications

  • Supports real-time, reminders, and lifecycle events

  • Prevents overload via prioritization and filtering

4. Domains & Events (FULL COVERAGE)

Note on Channels

Baseline channels (Push, Email, SMS, In-App) in all notification tables represent the default recommendation for each event.
Users can edit these per domain and event type in their notification settings.
This allows personalization, quiet hours, and channel preference without breaking critical alerts.

All the permissions will be based on the admin gcc and system user permission - items that will not be exposed to certain user will impact directly on the notifications
