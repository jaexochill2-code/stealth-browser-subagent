PRODUCT DEFINITION

AI Chat Assistant is a persistent, floating AI chatbot available on every screen:

  • Home

  • Leads

  • Calendar

  • Projects

  • Finance

  • Albums

  • Chat

  • Templates

  • Invoices

It is:

✔ Context-aware
✔ Role-aware
✔ Data-connected
✔ Risk-detection enabled
✔ Action-capable (not just informational)

It acts as:

  • Risk Manager

  • Operations Consultant

  • Financial Advisor

  • Sales Coach

  • Documentation Assistant

  • Communication Drafter

GLOBAL BEHAVIOR (ALL SCREENS)

  • Maintains conversation memory per session
