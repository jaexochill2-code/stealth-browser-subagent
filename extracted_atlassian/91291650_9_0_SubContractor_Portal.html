1. Product Overview

The Subcontractor Portal is a simplified execution interface allowing subcontractors to:

  • See assigned jobs

  • Complete checklist items

  • Upload proof (photos)

  • View files shared by GC

  • Send invoices

  • Message GC

It is action-oriented and minimal.

2. Target User

Primary User: Subcontractor
Technical Level: Low
Device: Desktop (tablet friendly)
