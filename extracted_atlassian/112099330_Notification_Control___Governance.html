1. Objective

Design a unified, scalable notification system that:

  • Works across Web + Mobile for all roles

  • Covers all domains (Leads → Projects → Finance → etc.)

  • Balances visibility vs noise

  • Gives users control (settings) without breaking critical alerts

  • Keeps UI clean and actionable

2. Core Principles

  1. Signal > Noise

  2. Actionable First (Inbox)

  3. System Controls Visibility (not user)

  4. User Controls Channels (settings)

  5. No hard delete (archive instead)
