 Overview

The Elbit Secure AI Knowledge & Project Support Platform will be deployed on-premises within Elbit’s secure network perimeter.

Architecture and technology stack will only be finalized after Elbit provides:

  • Infrastructure details (e.g., Azure Stack Hub / Azure Stack HCI / other on-prem hosting)

  • List of available/licensed Azure services (or equivalents)

  • Network and connectivity constraints (air-gapped, hybrid, etc.)

  • Security and compliance requirements

  • Approved integration patterns with existing systems (ERP, CRM, supply chain databases, etc.)

Process:

  1. Infrastructure Baseline (Elbit) – Elbit IT will provide detailed documentation of the available infrastructure, services, and security/compliance requirements.

  2. Solution Design (Vendor/Project Team) – Based on Elbit’s baseline, the solution team will propose:

    • Detailed solution architecture

    • Full technology stack (frontend, backend, AI/ML components, DB, APIs)

    • Deployment approach & scaling model

    • Security & integration design

  3. Joint Review – Architecture proposal will be reviewed and approved by Elbit IT and stakeholders before development begins.

Software quality attributes

Definition

Key success metrics

Notes

Efficiency

Optimal use of infrastructure resources to deliver required performance without waste.

  • CPU/memory utilization within defined thresholds

  • Response times < 2 seconds for 95% of queries

Efficiency targets may vary depending on Elbit’s available hardware and chosen AI stack.

Extensibility

Ease of adding new features and modules without major rework.

  • New modules integrated without affecting core services

  • Minimal regression defects after feature releases

Important for future phases (e.g., CRM integration, procurement automation).

Functionality

The system’s ability to provide the required features and meet specified use cases.

  • 100% of Phase 1 core features delivered as defined in PRD

  • Positive user acceptance test (UAT) results (>90% pass rate)

Functional scope to be validated during joint requirements review.

Integrity

Protection of data from unauthorized modification or corruption.

  • Zero data integrity breaches

  • Automated validation for document and database changes

Security and integrity controls must meet Elbit’s compliance requirements.

Interoperability

Ability to integrate and operate with Elbit’s existing systems and external data sources.

  • Successful API connections with ERP, CRM, and supplier systems

  • Compliance with Elbit’s integration standards

Vendor to confirm compatibility after infrastructure details are known.

Maintainability

Ease of maintaining the system over time, including bug fixes and updates.

  • Average bug resolution time < TBD days

  • Clear documentation for all components

Modular design preferred to minimize maintenance complexity.

Modifiability

Ability to make changes to existing components with minimal impact on others.

  • Low change impact score in regression testing

  • Modular service structure

Supports adaptability for evolving business needs.

Performance

Speed and responsiveness of the system under load.

  • ≤2-second response time for 95% of standard queries

  • Document search latency ≤1 second

Performance tuning will depend on final hosting and AI indexing architecture.

Portability

Ability to run in different environments with minimal changes.

  • System can migrate between approved Elbit environments without major refactoring

Especially relevant if infrastructure changes in the future.

Reliability

Consistency of correct operation over time.

  • MTBF (Mean Time Between Failures) meets or exceeds agreed SLA

  • Zero critical failures in production

Vendor to design with fault-tolerant components.

Scalability

Ability to handle increased load without performance degradation.

  • Handles 2x expected Phase 1 load without service failure

  • Linear scale with added resources

Depends on available infrastructure; may use horizontal/vertical scaling as allowed.

Security

Protection against unauthorized access, data breaches, and vulnerabilities.

  • Zero critical security incidents

  • All components pass penetration testing

Security approach will be defined by Elbit or proposed by vendor if none exists.

Usability

Ease of use and intuitiveness for end-users.

  • User satisfaction score ≥85% in post-deployment surveys

  • Minimal training required for core features

Includes chatbot usability and dashboard clarity.

Other

Adherence to industry, contractual, and government standards.

  • 100% compliance with Elbit-mandated frameworks

Critical for defense sector requirements.
