SCREEN 1 - HOME (Multiple Projects)

Allow customer to see all projects at a glance.

Displayed Data:

  • Project name

  • City

  • Status (In Progress / Completed)

  • Progress bar

  • Estimated finish date

Behavior:

  • Clicking “Open Project” → navigates to Project Overview.

  • If any proposal requires approval → alert banner shown at top.

User Flow:
Login → Land on Home → Select Project → Go to Project Overview
