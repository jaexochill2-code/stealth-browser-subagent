UI Behavior Notes

·       Compliance badge auto-refreshes after upload.

·       Tooltip on badge explains last document update.

·       Subcontractors with “Inactive” status are hidden from project assignment dropdowns.

·       All uploaded docs sync to Docs & Albums → Compliance Folder.

User Flow

  1. User navigates to Subcontractors tab.

  1. The system lists all subcontractors, their trades, and compliance statuses.

  1. User can filter, search, or add a new subcontractor.

  1. When a compliance doc is uploaded, AI verifies document type and expiry.

  1. Compliance badge updates automatically.

  1. Expiring Soon or Missing statuses trigger email & in-app alerts to both GC Admin and Sub.
