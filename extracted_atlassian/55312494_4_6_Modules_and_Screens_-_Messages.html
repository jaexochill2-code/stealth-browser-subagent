AI Logic

·       NLP Action Extraction:
Detects verbs or intent phrases like “need to”, “schedule”, “send invoice”, and auto-suggests tasks.

·       AI Summary Regeneration:
Every 10 messages, the system re-analyzes conversation for updated summary and open items.

·       Tone & Urgency Detection:
Flags urgent messages (e.g., “ASAP”, “blocked”) and recommends immediate escalation to PM or Admin.

·       Smart Mentions:
AI suggests relevant users to tag (e.g., “@Mike Wilson” when topic mentions electrical work).

 

UI Behavior Notes

·       Right panel updates dynamically with AI insights as conversation evolves.

·       Message timestamps adapt to user timezone.

·       Mentions (@user) trigger autocomplete list.

·       Files shared here automatically appear in project’s Docs & Albums → “Chat Uploads” album.

·       User roles define visibility (Customer sees limited threads).

 

User Flow

  1. User navigates to Projects → Messages Tab.

  1. System loads project-specific discussion thread.

  1. User types message, attaches files, or links a task.

  1. AI processes thread and updates summary, action suggestions, and related docs.

  1. Manager can summarize discussion or convert message to task.

System syncs attachments with Docs & Albums and task comments automatically.
