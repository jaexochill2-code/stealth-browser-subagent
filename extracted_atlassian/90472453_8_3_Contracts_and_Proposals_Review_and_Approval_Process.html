SCREEN 3 - CONTRACTS & PROPOSALS

Allow customer to review and approve contracts or change orders.

Displayed Data:

  • List of contracts and proposals

  • Status (Signed / Needs Approval / Approved / Rejected)

  • Amount

  • Date

Detail View:

  • Summary

  • Scope description

  • Cost impact

  • Timeline impact

  • Attachments

Actions:

  • Approve & Sign

  • Ask Question

  • Reject

Digital Signature Flow:

  1. Click Approve & Sign

  2. Signature modal opens

  3. Customer signs

  4. Status changes to Approved

  5. Notification sent to GC

User Flow:
Alert → Open Contracts → Review → Approve → Confirmation → Return Home.
