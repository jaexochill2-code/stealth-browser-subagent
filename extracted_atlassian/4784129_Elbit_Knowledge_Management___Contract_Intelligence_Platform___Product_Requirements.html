 Objective

Deliver a secure, AI-powered, on-premise knowledge management and project support platform tailored to Elbit’s operational workflows, data security requirements, and integration needs — enabling faster, more accurate decision-making across projects, contracts, and supply chain management.

 Assumptions

  • Elbit requires on-premises deployment due to data sensitivity.

  • Platform will integrate with existing Microsoft Azure Stack and Active Directory.

  • Initial deployment will focus on POC with core modules, followed by phased expansion.

  • Internal IT/security team will be available for integration support unless scoped otherwise.

  • Data sources (ERP, CRM, supplier feeds) will be accessible via API or secure file transfer.

 Milestones

[DRAFT]

  • Requirements Finalization & Security Review – 2 weeks

    • Confirm functional requirements for all modules.

    • Approve architecture and deployment plan.

    • Finalize UI/UX scope and branding guidelines.

  • Phase 1 (POC) Development – 8 weeks
    Backend / Core Services:

    • Implement Document Repository (with indexing & version control).

    • Build Project Database Service.

    • Develop initial Contract Intelligence engine (basic clause detection).

    • Implement AI RAG search pipeline.

    Frontend / UI:

    • Design initial UI wireframes and style guide (Figma).

    • Develop web dashboard for document search, project data, and contract insights.

    • Integrate AI Chat Assistant into dashboard.

  • POC Review & Internal User Testing – 3 weeks

    • Conduct UAT (User Acceptance Testing) for backend and frontend features.

    • Collect feedback on UI usability and AI accuracy.

    • Refine UX flows and fix high-priority issues.

  • Phase 2 (Post-POC Expansion) – 12 weeks
    Backend / Core Services:

    • Add Supply Chain Risk Engine.

    • Expand Contract Intelligence with advanced NLP and compliance alerts.

    • Add Dynamic Forms module for structured intake.

    Frontend / UI:

    • Develop new UI components for risk dashboards and forms.

    • Add role-based view customization (legal, procurement, project management).

    • Optimize for tablet and responsive layouts.

  • Full Rollout & Training – 4 weeks

    • Deploy final version to production environment.

    • Deliver user training sessions and documentation (incl. UI walkthroughs).

    • Monitor adoption and fine-tune UI/UX based on feedback.
