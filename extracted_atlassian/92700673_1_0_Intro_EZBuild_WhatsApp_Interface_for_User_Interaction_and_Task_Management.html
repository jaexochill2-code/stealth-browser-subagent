Product Type

External conversational operational interface

Purpose

Allow users to interact with EZBuild via WhatsApp to:

  • Pull information

  • Update system data

  • Execute actions

  • Receive AI-driven alerts

  • Manage tasks and approvals

Without logging into the web system.

General Principles

The WhatsApp Bot is an alternative interface to the Web Portal.

It does NOT:

  • Expand permissions

  • Override role restrictions

  • Expose hidden financial data

  • Allow structural edits

It only mirrors existing role capabilities.

System Characteristics

  • Role-based access

  • Phone-number authentication

  • Context-aware responses

  • Confirmation before critical actions

  • Permission filtering before data retrieval

  • AI-assisted command interpretation

Role Architecture

Users are grouped into 3 major categories:

  1. Team Members (Internal Users)

  2. Subcontractors

  3. Customers

Each has:

  • Different permission scope

  • Different AI visibility

  • Different action authority
