Dashboard

Purpose:
Display company-wide KPIs and portfolio analytics.

1. Overview

The EZBuild Dashboard System is the central operational and analytical hub of the platform.

The dashboard provides:

  • real-time company insights

  • operational visibility

  • project tracking

  • financial analytics

  • customizable KPI monitoring

  • role-based experiences

The system must support:

  • residential GCs

  • commercial GCs

  • remodeling companies

  • subcontractors

  • enterprise construction companies

The dashboard architecture will be:

  • modular

  • widget-based

  • customizable

  • responsive

  • role-aware

Primary Goals

Business Goals

  • Improve operational visibility

  • Increase user engagement

  • Centralize company performance

  • Support decision making

  • Create premium enterprise functionality

  • Increase customer retention

User Goals

  • Quickly understand company/project status

  • Track KPIs in real time

  • Identify delays and risks

  • Monitor budgets and payments

  • Prioritize daily work

5. Dashboard Architecture

The dashboard system contains 3 configuration levels.

A. Company-Level Dashboard

Managed by:

  • GCC Admin

Controls:

  • default layouts

  • enabled widgets

  • terminology

  • permissions

  • branding

B. Role-Based Dashboard

Each role receives:

  • dedicated layout

  • relevant KPIs

  • optimized widgets

Example:

  • Finance users see cash flow

  • PMs see milestones

  • Sales sees pipelines

C. Personal Dashboard

Users can:

  • hide widgets

  • reorder widgets

  • save preferences

  • set favorites
