1. Product Overview

The Customer Portal is a simple web interface designed for non-technical homeowners to:

  • View project progress

  • Review contracts and proposals

  • View invoices and payments

  • Access project photos and documents

  • Communicate with the contractor

It is read-only for most operational data and decision-based for approvals.

No internal construction data is exposed.

2. Target User

Primary User: Homeowner
Technical Level: Low
Device: Desktop (responsive tablet)
